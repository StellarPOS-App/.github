# StellarPOS-App/.github

Organization-wide files for [StellarPOS](https://github.com/StellarPOS-App):

- `profile/README.md`: the overview shown on the organization page
- `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `SUPPORT.md`:
  default community health files, used by any repository that does not
  define its own
- `ISSUE_TEMPLATE/` and `pull_request_template.md`: default issue forms
  and pull request template
