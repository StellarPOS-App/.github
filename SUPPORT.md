# Getting help

- **Something broken?** Open a bug report in the relevant repository:
  [surface](https://github.com/StellarPOS-App/surface/issues/new/choose),
  [backend](https://github.com/StellarPOS-App/backend/issues/new/choose), or
  [contracts](https://github.com/StellarPOS-App/contracts/issues/new/choose).
- **Have an idea?** Open a feature request in the same place.
- **Setup trouble?** Each repository's README has a quick start. The org
  profile shows how to run the whole stack locally.
- **Questions about Stellar or Soroban itself?** See the
  [Stellar developer docs](https://developers.stellar.org/).
- **Security issue?** Do not open an issue. Follow [SECURITY.md](SECURITY.md).
